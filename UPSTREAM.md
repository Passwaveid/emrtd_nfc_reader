# Upstream reference: AndyQ/NFCPassportReader

## Pin

- **PIN: `3bf545665c2a1c4c9f95e59e715239d71d1caeb7`** = release tag `2.3.2`
  (and `main` HEAD at verification time). Verified 2026-07-17.
- **No fork, no submodule.** Upstream's `Sources/` are fetched from public
  GitHub (`https://github.com/AndyQ/NFCPassportReader.git`) at the PIN and
  **SHA-verified** on every Swift-runner session. Git object names are
  content-addressed, so a matching SHA is proof the tree is byte-identical to
  what the port was written against; that check *is* the pin mechanism.
- The test-enabling changes live
  in this repo as [swift-runner/seams.patch](swift-runner/seams.patch) (345
  lines: the `ConformanceTests` target declaration, the injectable RNG and
  ephemeral-key seams, two `*TestSeams.swift` files, a few access-level
  relaxations) plus [swift-runner/ConformanceTests/](swift-runner/ConformanceTests/)
  (15 files, 3 142 lines, ours outright). `swift-runner/run.sh` reassembles
  the buildable package from the three pieces. The rule:
  `seams.patch` only ever carries test-enabling changes (test targets,
  injectable seams, access-level relaxations for testing); **never protocol
  changes**.
- Archival: a `git bundle` of the full pre-migration fork history (280 commits,
  51 tags, `test-seams` at `7bf1dc5`) is kept outside the repo. Point
  `UPSTREAM_BUNDLE` at it to run offline, or if AndyQ/NFCPassportReader ever
  disappears.

## Sync procedure

1. `git log 3bf5456..main --oneline` against a throwaway clone of
   `https://github.com/AndyQ/NFCPassportReader.git`.
2. Review new commits and add the wanted fixes to the to-port list below.
   Where one fixes a defect the port already fixes (see Divergences), that
   row's split swift/dart conformance cases merge back into shared ones.
3. To adopt: advance `UPSTREAM_PIN` in `swift-runner/run.sh` and the PIN here,
   re-apply `seams.patch` against the new tree (regenerate it if any hunk has
   drifted: `swift-runner/README.md`, "Maintaining seams.patch"), log the port
   in "Fixes ported since PIN", and book an ad-hoc rented-Mac session to re-run
   affected suites.

## Divergences

Every deliberate behavioral departure from upstream, fixes and additions
alike. Fidelity to upstream remains the baseline correctness claim
everywhere no entry below says otherwise.

| Where | Departure |
|---|---|
| `unpad` | empty/all-zero input: upstream index-underflow crash -> `InvalidDataPassed`; dart-only vectors |
| `asn1Length` / `toAsn1Length` | input too short for its length form (upstream out-of-range crash) -> `CannotDecodeASN1Length`; negative length (upstream emits garbage via `%02x`) -> `InvalidASN1Value`; dart-only vectors |
| `intToBin` | even-width hex encoding at both pad settings (`300 -> 01 2C`; upstream mangles to `12 0C` via the odd-length quirk); split swift/dart vectors pin both behaviors |
